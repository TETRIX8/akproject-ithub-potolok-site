# ITHUB Потолка · Akproject

Игровой сайт с авторизацией NewLXP, профилем пользователя, рейтингом, тапами, крестами и общей таблицей лидеров.

## Возможности

- авторизация через GraphQL API NewLXP;
- серверная сессия без передачи access token в браузер;
- игровая механика с уровнями и сообщениями;
- сохранение тапов, рейтинга и крестов в SQLite;
- кнопка обмена креста на повышение рейтинга;
- общая таблица лидеров;
- адаптивная раскладка для ПК и мобильных устройств;
- анимация загрузки и состояния авторизации.

## Структура

- `index.html` — основная игровая страница;
- `lxp_gateway.py` — Flask-шлюз авторизации и API рейтинга;
- `lxp-gateway.service` — пример systemd-сервиса;
- `lxp-location.conf` — пример reverse-proxy маршрута nginx.

## Безопасность

Пароли, токены, реальные учетные данные и production-база данных в репозиторий не входят. Email и пароль вводятся пользователем через форму сайта и передаются серверному шлюзу по HTTPS.

Перед запуском нужно заменить `API_URL` при необходимости и настроить секреты окружения/HTTPS на сервере. SQLite-база создаётся автоматически в `/var/lib/lxp-gateway/users.sqlite3`.

## Локальный запуск

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install flask requests
python3 lxp_gateway.py
```

Статическую страницу можно открыть через nginx или любой локальный HTTP-сервер. Для production рекомендуется использовать systemd и reverse proxy nginx.
